Gizlilik politikası / Privacy policy

English

"singleplayer bot" (the "App") is a personal automation tool operated by the owner of the singleplayer_tr accounts. It is used only by its owner.

What the App does. It uploads short videos produced by the owner to the owner's own YouTube channel using the YouTube API Services, and publishes the owner's own posts to the owner's own Instagram account.

Data we access. With the owner's authorization, the App uses the YouTube scope that allows uploading videos and reads the owner's own channel name to confirm the connection. The App does not access, collect, store or share any personal data of other users or viewers.

Storage. The OAuth credentials (refresh token) for the owner's channel are stored as encrypted secrets in the owner's private GitHub repository and are used only to upload the owner's videos. No user data is sold or shared with third parties.

Revoking access. Access can be revoked at any time at Google security settings (https://myaccount.google.com/permissions).

Data deletion. The App keeps only the IDs and URLs of the owner's own uploaded videos (to avoid duplicate uploads), for up to 30 days. To delete all stored data, the owner revokes access at https://myaccount.google.com/permissions and deletes the stored credentials; any user may request deletion by emailing tncyhm@gmail.com — requests are completed within 7 days. Revoking access immediately stops all API use.

YouTube API Services. The App uses YouTube API Services. By using it you agree to the YouTube Terms of Service. See also the Google Privacy Policy (http://www.google.com/policies/privacy).

Contact. tncyhm@gmail.com

Türkçe

"singleplayer bot", singleplayer_tr hesaplarının sahibinin yalnızca kendisi için kullandığı kişisel bir otomasyon aracıdır.

Ne yapar? Hesap sahibinin ürettiği kısa videoları YouTube API Hizmetleri ile sahibin kendi YouTube kanalına yükler; sahibin kendi gönderilerini kendi Instagram hesabında yayınlar.

Hangi verilere erişir? Sahibin izniyle yalnızca video yükleme yetkisini kullanır ve bağlantıyı doğrulamak için sahibin kendi kanal adını okur. Başka kullanıcıların ya da izleyicilerin kişisel verilerine erişmez, bunları toplamaz, saklamaz, paylaşmaz.

Saklama. Kanala erişim anahtarı, sahibin gizli GitHub deposunda şifreli olarak saklanır ve yalnızca sahibin videolarını yüklemek için kullanılır. Veri satılmaz, üçüncü taraflarla paylaşılmaz.

İzni geri alma. Google güvenlik ayarlarından istediğiniz zaman kaldırılabilir.

Veri silme. Uygulama yalnızca sahibin kendi yüklediği videoların kimlik ve adreslerini (tekrar yüklemeyi önlemek için) en fazla 30 gün saklar. Tüm veriler, Google izni kaldırılıp saklanan anahtar silinerek yok edilir; silme talepleri tncyhm@gmail.com adresine yapılabilir ve 7 gün içinde tamamlanır.

YouTube API Hizmetleri. Uygulama YouTube API Hizmetlerini kullanır; YouTube Hizmet Şartları ve Google Gizlilik Politikası geçerlidir.

İletişim. tncyhm@gmail.com
